# Linear Regression with L2 Regularization

Реализация линейной регрессии с L2-регуляризацией (Ridge) с использованием объектно-ориентированного подхода.

## Особенности проекта
* Логика разделена на классы метрик и самой модели.
* Алгоритм обновления весов и расчет потерь реализованы вручную.
* Обучение прерывается автоматически при достижении сходимости весов (параметр `epsilon`).

## Математическая база

В основе лежит минимизация функции потерь с добавлением квадратичного штрафа за величину весов:

$$J(w) = \frac{1}{2} \sum_{i=1}^{n} (y_{true} - y_{pred})^2 + \alpha \sum_{j=1}^{m} w_j^2$$

Обновление весов (Gradient Descent Step):
$$w_{new} = w_{old} - \eta \cdot \left( \sum (y_{pred} - y_{true}) \cdot X + 2\alpha w \right)$$

Где:
* $\alpha$ (alpha) — коэффициент регуляризации.
* $\eta$ (lr) — скорость обучения (learning rate).

## Структура классов

### 1. `LinearMetrics`
Содержит статические методы для оценки качества модели:
* `loss(y_true, y_hat)` — стандартная квадратичная ошибка (MSE/2).
* `loss_with_l2(y_true, y_hat, weights, alpha)` — функция потерь с учетом L2-штрафа.

### 2. `LinearRegressionL2`
Управляет процессом обучения:
* `__init__` — инициализация параметров ($\alpha$, $\eta$, начальные веса).
* `update_weights` — вычисление градиента и обновление весов.
* `train` — основной цикл обучения с логированием эпох и проверкой условия остановки.
