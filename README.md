# Реализация L2-регуляризации (Ridge) с нуля на Python

Этот проект демонстрирует математическую основу L2-регуляризации (Ridge Regression). В коде реализован процесс вычисления функции потерь и градиентного спуска для настройки весов модели вручную, а также сравнение с использованием библиотеки `scikit-learn`.

## ⚙️ Технологии
* **Python 3.x**
* **NumPy**: Математические вычисления и работа с массивами.
* **Matplotlib**: Визуализация данных и кривой регрессии.
* **Scikit-learn**: Сравнение с эталонной реализацией Ridge.

## 📈 Математическая модель

В проекте используется функция потерь MSE с добавлением $L2$-штрафа:

$$Loss = \frac{1}{2} \sum_{i=1}^{n} (y_{true} - y_{pred})^2 + \alpha \sum_{j=1}^{m} w_j^2$$

Обновление весов происходит по формуле:

$$w_{new} = w_{old} - \eta \cdot (\frac{\partial Loss}{\partial w} + 2\alpha w)$$

Где:
* $\alpha$ — коэффициент регуляризации.
* $\eta$ — скорость обучения (learning rate).
