Регуляризация Линейной Регрессии: OOP Implementation
Репозиторий содержит объектно-ориентированную реализацию алгоритма линейной регрессии с применением L2-регуляризации (Ridge). Проект демонстрирует ручное управление весами через градиентный спуск без использования высокоуровневых библиотек машинного обучения для этапа тренировки.
🧱 Архитектура проекта
Код разделен на два ключевых компонента:

LinearMetrics: Статический класс для расчета метрик.

loss: Стандартная квадратичная ошибка.

loss_with_l2: Функция потерь с учетом штрафа за величину весов.

LinearRegressionL2: Основной класс модели.

Инкапсулирует параметры обучения (alpha, lr).

Реализует метод update_weights для шага градиентного спуска.

Управляет циклом обучения через метод train с поддержкой ранней остановки (epsilon).
